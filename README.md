## Projeto

#### Sistema acadêmico desenvolvido em C# com ASP.NET Web Forms (.NET Framework) utilizando Entity Framework 6 para persistência de dados e SQL Server LocalDB como banco de dados.
O projeto implementa funcionalidades de autenticação de usuários com JWT (JSON Web Token) e hash de senhas utilizando SHA-256, aplicando conceitos de segurança e criptografia.
Inclui operações de CRUD, organização em camadas e integração entre interface web e backend.

Principais aprendizados:

– ORM com Entity Framework

– Autenticação e segurança de dados

– Estrutura de aplicações Web Forms

– Conexão e modelagem de banco de dados SQL Server
